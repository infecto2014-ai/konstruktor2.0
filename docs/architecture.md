# Архитектура

## Клиент и рендер

Эта версия — отдельная реализация на TypeScript и React с общими типами/схемами проекта в `shared/`. Она заменяет предыдущий статический JavaScript-конструктор, чтобы модель, интерфейс, сетевой обмен и серверные проверки использовали один контракт.

Принт рисуется Canvas 2D. Это позволяет использовать одну геометрию в редакторе и при PNG-экспорте, хранить объекты в миллиметрах в JSON и загружать Noto Sans / Noto Serif с поддержкой редактируемого текста. Используемая модель объектов не зависит от размеров экранного canvas. Экспорт рассчитывает пиксели из миллиметров и DPI. Интерактивное выделение и манипуляторы находятся в SVG поверх canvas.

## Данные и хранение

- Проекты сериализуются по строгой Zod-схеме; в IndexedDB хранятся локальные черновики вместе с исходными файлами. Черновики индексируются по значению `location.hash` (source URL fragment); отдельный указатель `last` ускоряет восстановление последнего проекта, не заставляя разные ссылки и iframe перезаписывать друг друга. После обновления URL сохранённого проекта локальный черновик с совпадающим fragment восстанавливается при refresh.
- История Undo/Redo держит до 50 снимков модели проекта в памяти. Перетаскивание объединяется в одну запись истории.
- На сервере локально используется SQLite из `node:sqlite`, а при `DATABASE_URL` — PostgreSQL. Метаданные и транзакционные данные находятся в БД; сами файлы по умолчанию сохраняются в `DATA_DIR/assets`.
- `STORAGE_DRIVER=s3` направляет файловые объекты в S3-совместимое хранилище; при таком режиме `S3_BUCKET` обязателен. Для внешних credentials используется цепочка AWS SDK.
- Заявки сохраняются как неизменяемые снимки; уникальный idempotency key обеспечивает повторную отправку без создания дубликата.

## Доступ к проектам и файлам

Публичного списка проектов нет. Идентификатор проекта/файла дополняется случайным bearer token; сервер хранит хеш секрета и сравнивает его в постоянное время. Ссылка на проект несёт токен в URL fragment, который не уходит в HTTP-запрос как заголовок `Referer`. API загрузки использует токены доступа. Снимок заявки содержит сведения для восстановления заказа и ссылки доступа, поэтому файл снимка следует хранить конфиденциально.

## Производственные границы

Экспорт создаёт прозрачный PNG и демонстрационные превью. Конвертация в CMYK/PDF, спуск полос, согласование цветового профиля/белой подложки, утверждение технологом, оплата и доставка не реализованы. Подробности — в разделе ограничений [README](../README.md) и [проверках](verification.md).

В проекте не настроены автоматические резервные копии, восстановление и политика сроков хранения/удаления данных. Для production эти процессы нужно определить и настроить отдельно.

## Ссылка на интерфейсный ориентир

Туда не загружали макеты, не оформляли заказ и не копировали дизайн или ассеты; ссылка фиксирует только доступный интерфейсный ориентир.
