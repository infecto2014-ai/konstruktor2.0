# Embed-интеграция

Конструктор встраивается с origin приложения, например `http://localhost:5173/embed`. Страница-хост в этой сборке доступна отдельно на `http://localhost:5174`. Хост принимает сообщения только от точного origin приложения и окна iframe; `constructor:height` меняет высоту iframe только при конечном числе в диапазоне 200–20000 px.

Все сообщения используют оболочку `{ channel: "souvenir-constructor", version: 1, type, payload }`. Входящий `host:init` проверяется строгой схемой, разрешённым origin из `ALLOWED_ORIGINS`, а также `event.source === window.parent`. Для отправки конструктор использует явный origin хоста, полученный из проверенного `document.referrer` или принятого сообщения. Хост также проверяет одновременно точный origin конструктора и `event.source === iframe.contentWindow`.

## Хост → конструктор

```js
{
  channel: 'souvenir-constructor',
  version: 1,
  type: 'host:init',
  payload: { productId: 'classic', colorId: 'blue', size: 'L' }
}
```

`productId` обязателен; `colorId` и `size` необязательны. Значения сверяются с каталогом. Пример вызова и точный `targetOrigin` находятся в `public/host.html`.

## Конструктор → хост

| `type` | Payload | Когда отправляется |
|---|---|---|
| `constructor:ready` | `{}` | Хост доверен, каталог загружен и конструктор готов к связи. |
| `constructor:height` | `{ height: number }` | Обновилась высота документа, измеренная в CSS-пикселях. |
| `project:saved` | `{ id: string }` | Проект сохранён на сервере. |
| `order:created` | `{ id: string, number: string }` | Демонстрационная заявка сохранена. |
| `constructor:error` | `{ message: string }` | Неизвестен товар или вариант из входного сообщения. |

Сообщения для хоста не содержат контактов клиента, паролей или bearer tokens. Токен и URL проекта остаются в интерфейсе конструктора и не передаются в событии сохранения. Хост показывает только проверенное название события и не выводит payload.

События `project:saved` и `order:created` сообщают статус, но не раскрывают данные проекта, заявку целиком или контакт пользователя. На уровне безопасности этот контракт не заменяет серверную авторизацию API.
