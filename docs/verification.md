# Проверки

## Автоматические проверки

- `npm test`: **17 пройдено из 18, 1 пропущен**. Пропуск — PostgreSQL integration test, который выполняется только при заданном `PG_TEST_URL` на отдельной временной базе.
- `npm run build`: TypeScript проверка и Vite production build прошли.
- Проверка dependency audit: **0 найденных уязвимостей**.

## Ручная проверка в браузере

Проверены desktop и мобильный viewport шириной 360 px в встроенном браузере. Использовались синтетические локальные данные, а не реальные клиентские макеты.

- На обеих сторонах размещались изображение 300 × 200 px и русские надписи `Привет, мир!\nЙё — моя идея` (перед) и `СОЗДАВАЙ СВОЁ` (спина).
- Для изображения с эффективным разрешением 54 DPI показано предупреждение о качестве. Макет, выходящий за границу, блокировал оформление.
- Проверены Undo/Redo текста, удаление и повторное восстановление через Undo.
- Проверено восстановление локального IndexedDB черновика после исправления начального отступа текста.
- Серверный проект сохранялся и повторно открывался по ссылке. На телефоне заявка на 170 000 копеек сохранилась.
- После сохранения проекта и изменения URL локальный черновик сохранился с новым source hash. После обновления страницы восстановился несохранённый слой `ТВОЯ ИСТОРИЯ`.
- На телефоне оформлена заявка с новым изображением на переде и прежним изображением на спине. ZIP содержал 7 элементов: `order.json`, 2 оригинала, 2 PNG печати и 2 превью.
- Оба печатных PNG имели размер 2835 × 3780, PNG pHYs соответствовал 300 DPI, alpha присутствовал. Проверенный пиксель нового изображения находился в ожидаемой точке `(1417, 2717)` со значением RGBA `(245, 196, 96, 255)`. Превью имели размер 600 × 680.
- Desktop и мобильный экспорт имели одинаковые размеры 2835 × 3780. При сравнении распакованных каналов 15 значений из 42 млн отличались максимум на 7 уровней. Причина различий не установлена; побайтовое равенство не проверялось и не заявляется.
- Embed с origin `localhost:5174` в `localhost:5173/embed` принят; `host:init` с classic/blue/L сработал. После сохранения хост получил `project:saved` и показал «Макет сохранён».
- Отдельно production smoke проверил `http://localhost:5180/embed`: собранный клиент и API открылись без Vite middleware.

## Не проверено

- PostgreSQL: интеграционный прогон пропущен без `PG_TEST_URL` и доступной тестовой БД.
- S3: не проверялся, нет настроенного endpoint и credentials.
- Глобальная настройка браузера для блокировки third-party cookies не менялась. Приложение и его API не требуют cookies для описанного сценария.
- Production-деплой, реальные заказы/данные, физический тест отпечатка и согласование производственного процесса не выполнялись.
- Резервное копирование, восстановление и retention не настроены и не проверялись.
